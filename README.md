# Controle de Tarefas (Back-end)
Utilizando Spring boot, esse projeto visa aperfeiçoar minhas habilidades com Spring e suas tecnologias para fazer um servidor back end completo.
Esse projeto é um sistema de tarefas que organiza os afazeres do usuários.

## Modelos
Para esse projeto há 3 entidades: Tarefa, Dashboard e Usuario.
- Tarefa : Representa o card que tem as informações gerais da ação. (Inclui título, descrição, data de início e final)
- Dashboard : É o espaço de trabalho onde armazena Tarefas.
- Usuario : É o usuário do sistema. Cada usuário tem seus dashboards.
